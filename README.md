# BLCNYY's Homebrew tap

```sh
brew tap blcnyy/tap
brew trust --cask blcnyy/tap/purrloader
brew install --cask purrloader
```

Homebrew asks you to trust casks from taps outside its own, which is what the second line does.

[Purrloader](https://github.com/BLCNYY/Purrloader) is a Mac app for saving videos.
